# Built with Codex

A collection of projects, experiments, and hands-on learning exercises built with OpenAI Codex, with readable code and step-by-step explanations.

## AI fundamentals

Practical examples for learning how machine-learning models work, starting with a tiny next-word predictor built in Python.

- [Read the detailed lesson](AI%20fundamentals/predicting%20next%20word%20using%20existing%20words/Read.md)
- [Explore the commented Python code](AI%20fundamentals/predicting%20next%20word%20using%20existing%20words/code.py)

The first example learns to predict **tea** after **I drink**. It explains word counts, weights, biases, softmax, loss, and training updates using actual numerical calculations. It is a small teaching model, not a full LLM.
